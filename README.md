🍔 Flutter Firebase Food Delivery Web App

A Flutter Web based Food Delivery Application powered by Firebase, designed for fast, scalable, and real-time food ordering and management.

🚀 Features

🔐 Firebase Authentication (Admin / User)

🍽️ Browse restaurants & food items

🛒 Cart & order placement

📦 Real-time order tracking

🧾 Order history

🖥️ Responsive Web UI (Desktop & Mobile)

🔄 Real-time updates using Firestore

☁️ Cloud storage for images

🛠️ Tech Stack

Frontend: Flutter (Web)

Backend: Firebase

Firebase Authentication

Cloud Firestore

Firebase Storage

Firebase Hosting

🔐 Authentication Roles

Admin

Manage food items

View & update orders

User

Browse menu

Place orders

Track order status
